## 구현된 학습 흐름

대시보드, 적응형 12개 표본 진단, 오늘의 학습, 복습 대기열, 플래시카드, 문맥별 의미, 연어 선택 테스트, 정밀해석 4개, 장문 독해 9세트, 오답 노트, 통계, 단어/후보 검색, 메모, 설정, 다크 모드, JSON/CSV 내보내기, JSON 학습/어휘 복원, 서비스 워커 오프라인 캐시를 제공합니다.

독해 9세트는 요청한 9가지 유형을 포함합니다. 기존 시험 문제를 복사하지 않고 자체 작성했으나 분량과 난도는 실제 시험 대비 작습니다. 실제 TOEIC 예상 점수를 산출하지 않습니다. 자유 번역은 자기 확인이며 자동 의미 채점이 아닙니다.

별도 코드 리뷰에서 발견한 다중 탭 덮어쓰기, 고정된 문맥 큐, 진단 난이도 이중 조정, 정답 공개 이후 시간 포함, 맞힌 문제의 근거 오류 누락, 진단 이해 단계 미기록을 수정했습니다. 트랜잭션 저장, 큐 순환, 근거 오류, 응답 시간은 회귀 테스트로 검증했습니다.

## 남은 작업 및 재개 순서

1. **대규모 콘텐츠 완성:** 4,000–6,000개 표제어를 검토하는 후보 규모는 확보했지만 학습 가능한 콘텐츠는 199개 표제어에 그칩니다. `npm run data:next`로 후보를 받아 25개 이하 배치로 뜻·예문·번역·표현을 추가하고 검증합니다. 1,500–3,000개 표현 목표도 미달입니다.
2. **언어 검수:** 전문 검수자의 실제 확인과 증거를 별도 기록한 뒤 검수 완료 상태로 전환할 운영 절차가 필요합니다. 현재 파이프라인은 생성물을 항상 needs-review로 출력합니다.
3. **전이 문맥 확장:** 30개 의미 외의 항목은 예문이 하나입니다. 단일 문맥 반복만으로 숙달하지 않게 되어 있지만, 충분한 새 문맥을 제공하기 전에는 해당 의미의 숙달 판정이 제한됩니다.
4. **어휘군 정규화:** 문자열 중복은 병합하지만 파생어군·동의 구동사 관계는 수동 관리입니다. 의미가 유사한 표제어를 기계적으로 합치지 않았습니다.
5. **학습 알고리즘 개선:** 현재 SM-2 변형은 기존 간격과 난이도 계수를 사용합니다. FSRS의 기억 안정도/경과시간 기반 파라미터 최적화는 구현하지 않았습니다. 진단의 난이도와 10초 느린 인출 기준도 경험적 앱 기준입니다.
6. **더 깊은 통계:** 숙달은 현재 의미 수 중심입니다. 표제어 전체 의미 숙달 집계, 다의어 오류율 세분화, 지문 난도를 보정한 속도 추세, 모의고사 연계는 추가 구현 대상입니다.
7. **기기 검증:** 실제 iOS Safari/WebKit·Android 실기기·브라우저 저장 공간 부족/OS 강제 종료 검증은 남아 있습니다. 현재 모바일 테스트는 Chromium 화면 에뮬레이션입니다.
8. **확장 기능:** 선택적 AI 의미 평가, 클라우드 동기화, 앱 내 개별 어휘 편집은 미구현입니다. 핵심 기능은 API 키 없이 작동하며, 어휘 수정은 소스 배치 또는 검증된 JSON 복원을 이용합니다.

전체 요청이 완성되었다는 보고가 아닌, 실행 가능한 첫 버전과 재개 가능한 콘텐츠 구축 단계의 현황입니다.
