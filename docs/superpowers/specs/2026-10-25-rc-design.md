# RC Vocabulary Lab 설계
요구사항: ../../REQUEST.md. 사용자가 구현을 명시적으로 요청했으므로 추가 승인 없이 진행.
React/TypeScript 정적 PWA, IndexedDB 원자적 저장, 서버 및 API 키 불필요.
대안: 서버 동기화는 계정·운영 비용 및 오프라인 충돌을 추가하므로 후속 확장. buildless JS보다 TS를 선택해 학습 이벤트 및 복원 검증 강화.
표제어(후보 포함), 의미(한국어·예문·독립 일정), 표현(의미 링크)을 분리. 원본 후보는 CC BY-SA 4.0, 새 콘텐츠도 동일 라이선스로 배포. 생성 콘텐츠는 human-reviewed가 아닌 needs-review.
SM-2 원리를 적용한 명시적 변형: 실패 10분, 성공 1/6/이후 EF배 일, 확신 낮음 최대 1일. 자기 평가는 객관식/인출 기록과 분리. 숙달은 서로 다른 문맥의 인출+객관식 성공, 3일 이상 분산된 관찰, 최근 실패 없음 요구. 이는 앱 내 보수적 기준이며 검증된 TOEIC 예측 모델 아님.
한국어 자유 번역은 자동 채점하지 않고 해설/의미 단위 체크리스트로 자기 확인. 단어 인출은 제한된 허용 답 비교이며 자유 번역과 구분.
전체 학습 가능한 데이터 목표는 수천 개이나 한 번의 생성으로 정확도를 보장하지 않음. 실제 파일 수 기반 현황, 재개 가능한 25개 배치, 출처·품질 상태 유지.
